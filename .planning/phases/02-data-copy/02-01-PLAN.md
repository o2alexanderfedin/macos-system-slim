**Script structure (top to bottom):**

1. **Shebang and strict mode:** `#!/bin/bash` then `set -euo pipefail`

2. **Header comment:** Purpose, requirements covered (MIGR-01, MIGR-02, MIGR-03, MIGR-04), safety notes

3. **Constants** (per D-03, D-04):
   - `SOURCE="$HOME/Library/Containers/com.docker.docker/Data/vms/0/data/Docker.raw"`
   - `DEST="/Volumes/Unitek-B/Docker/Docker.raw"`
   - `POLL_INTERVAL=5` (per D-05, Claude discretion on exact value)

4. **Helper functions** (same pattern as preflight.sh):
   - `copy_pass()` / `copy_fail()` / `copy_info()` with `[ PASS ]` / `[ FAIL ]` / `[ INFO ]` format
   - `copy_abort()` with ABORT message and exit 1
   - `cleanup_partial()` that prints what it is deleting (anti-pattern from research: never delete silently) then runs `rm -f "$DEST"`

5. **Docker-stopped guard** (per Pitfall 5 from research):
   - Check `pgrep -f 'Docker' 2>/dev/null` — abort if any Docker process detected
   - Same process list as preflight.sh: Docker Desktop, com.docker.backend, com.docker.virtualization, com.docker.helper, com.docker.build

6. **Source file guard:**
   - Verify `$SOURCE` exists with `test -f`
   - Abort if missing

7. **Optional pre-copy space guard** (Claude discretion — include it, belt-and-suspenders):
   - `REQUIRED_KB=$(du -sk "$SOURCE" | awk '{print $1}')`
   - `AVAIL_KB=$(df -k /Volumes/Unitek-B | awk 'NR==2 {print $4}')`
   - Abort if `AVAIL_KB -lt REQUIRED_KB`

8. **Capture source sizes for later verification** (per D-08):
   - `SRC_LOGICAL=$(stat -f %z "$SOURCE")`
   - `SRC_DISK_KB=$(du -sk "$SOURCE" | awk '{print $1}')`
   - Print both with `copy_info`

9. **run_copy function:** Takes a copy command string as argument.
   - Delete any existing partial destination first: `rm -f "$DEST"`
   - Get `EXPECTED_KB` from source via `du -sk`
   - Launch copy in background: `$1 "$SOURCE" "$DEST" &` and capture `COPY_PID=$!`
   - Polling loop per D-05, D-06, D-07: `while kill -0 "$COPY_PID" 2>/dev/null; do` (the `2>/dev/null` handles Pitfall 4 — set -e won't trigger on kill -0 failure)
     - `CURRENT_KB=$(du -sk "$DEST" 2>/dev/null | awk '{print $1}' || echo 0)` (handles Pitfall 2)
     - Calculate percentage with `bc` only when both `EXPECTED_KB -gt 0` and `CURRENT_KB -gt 0`
     - Render progress bar: `printf "\r  [ COPY ] [%-50s] %3d%%" "$BAR" "$PCT"` with `BAR=$(printf '#%.0s' $(seq 1 "$BARS") 2>/dev/null || true)`
     - When sizes are zero, show `printf "\r  [ COPY ] starting..."`
     - `sleep $POLL_INTERVAL`
   - After loop: `printf "\n"`, then `wait $COPY_PID` and capture exit code
   - Return the exit code

10. **Copy execution** (per D-01, D-02, D-11, D-12):
    - Print header: "Docker.raw Copy"
    - Attempt 1: `run_copy "cp -c"`
    - If exit code non-zero:
      - `copy_info "cp -c failed (exit $EXIT_CODE) -- cleaning partial and retrying with ditto"`
      - `cleanup_partial`
      - Attempt 2: `run_copy "ditto"`
      - If exit code non-zero:
        - `cleanup_partial`
        - `copy_fail "Both copy methods failed"`
        - `copy_abort "Cannot copy Docker.raw. Check disk space, volume mount, permissions."`
    - On success: `copy_pass "MIGR-01: Docker.raw copied to $DEST"`

11. **Post-copy verification** (per D-08, D-09, D-10):
    - `sleep 2` before verification (per Open Question 1 — APFS flush)
    - Compare logical sizes: `DST_LOGICAL=$(stat -f %z "$DEST")` vs `SRC_LOGICAL`
    - Compare on-disk sizes: `DST_DISK_KB=$(du -sk "$DEST" | awk '{print $1}')` vs `SRC_DISK_KB`
    - Logical size: exact match required. PASS or FAIL (MIGR-02a)
    - On-disk size: if exact match, PASS. If within 1% difference, PASS with INFO note about APFS compression. If >1% difference, FAIL (MIGR-02b)
    - 1% threshold calculation: `THRESHOLD=$(echo "scale=0; $SRC_DISK_KB / 100" | bc)`

12. **Verify original untouched** (per D-13):
    - Re-read `stat -f %z "$SOURCE"` and compare to `SRC_LOGICAL` captured earlier
    - PASS or FAIL

13. **Summary** (same format as preflight.sh):
    - Print total PASS and FAIL counts
    - If FAIL > 0: `copy_abort "Verification failed -- do not proceed to Phase 3"`
    - If FAIL == 0: Print success message, suggest running verify-copy.sh

Make the script executable: `chmod +x`.
