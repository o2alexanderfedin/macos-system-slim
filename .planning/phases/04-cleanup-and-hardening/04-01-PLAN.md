   - On success, `harden_pass "CLEAN-03 + CLEAN-04: Hardening keys written to both settings files"`
4. **D-07 restart Docker**: `open -a "Docker Desktop"`. Poll with `docker info` every INTERVAL seconds up to TIMEOUT. Print progress. If timeout, `harden_abort`. On success, `harden_pass "Docker daemon ready"`
5. **D-08 post-restart readback verify**: Python one-liner to re-read settings-store.json and verify `AutoDownloadUpdates` is False, `DisableUpdate` is True, `AutoStart` is False.
