Create `.planning/phases/01-pre-flight/preflight.sh` — a bash script that runs all pre-flight checks in fail-fast order. Use the script skeleton from 01-RESEARCH.md (lines 314-419) as the base, with these specific requirements:

**Script header:**
```
#!/bin/bash
set -euo pipefail
```

**Constants (exact values):**
```bash
DOCKER_SETTINGS_DIR="$HOME/Library/Group Containers/group.com.docker"
DOCKER_RAW_PATH="$HOME/Library/Containers/com.docker.docker/Data/vms/0/data/Docker.raw"
TARGET_DIR="/Volumes/Unitek-B/Docker"
```

**Check order (per D-05 fail-fast, cheapest first):**

1. **PREFLT-01 (per D-01, D-02):** Docker process kill and verify sequence:
   - `osascript -e 'quit app "Docker Desktop"' 2>/dev/null` then `sleep 3`
   - `killall -9` for: `Docker Desktop`, `com.docker.backend`, `com.docker.virtualization`, `com.docker.helper`, `com.docker.build` (per open question 1 in research)
   - Each killall must have `2>/dev/null || true` (per Pitfall 3 — killall errors on no-match)
   - Verify with `pgrep -f` for each process name; collect any PIDs
   - If any PID found: `preflight_fail` then `preflight_abort` (per D-02 hard block)

2. **PREFLT-02 (per D-06):** APFS format check:
   - `diskutil info /Volumes/Unitek-B` piped through `awk -F': ' '/Type \(Bundle\)/ {gsub(/^[[:space:]]+|[[:space:]]+$/, "", $2); print $2}'`
   - Must equal `apfs` exactly (per Pitfall 4 — do NOT grep for "APFS" anywhere else)
   - If not `apfs`: abort

3. **PREFLT-03 (per D-07):** Free space >= 2x Docker.raw on-disk:
   - `du -sk "$DOCKER_RAW_PATH"` for on-disk size in KB
   - `REQUIRED_KB=$((DOCKER_RAW_KB * 2))`
   - `df -k /Volumes/Unitek-B | awk 'NR==2 {print $4}'` for available KB
   - Convert to GB for display using `bc` with `scale=1`
   - If `AVAIL_KB < REQUIRED_KB`: abort

4. **PREFLT-05:** Target directory writable:
   - `mkdir -p "$TARGET_DIR"` if absent
   - `touch "$TARGET_DIR/.preflight_write_test" && rm "$TARGET_DIR/.preflight_write_test"`
   - If touch/rm fails: abort

5. **PREFLT-04 (per D-03, D-04):** Backup both settings files:
   - `cp "$DOCKER_SETTINGS_DIR/settings-store.json" "$DOCKER_SETTINGS_DIR/settings-store.json.bak"`
   - `cp "$DOCKER_SETTINGS_DIR/settings.json" "$DOCKER_SETTINGS_DIR/settings.json.bak"`
   - Verify both `.bak` files exist with `[[ -f ... ]]`
   - If either missing: abort

6. **D-05 bonus checks:** Virtualization backend + diskSizeMiB resolution:
   - Extract `UseVirtualizationFramework` from `settings-store.json` using `python3 -c "import json; ..."`
   - Must equal `True`; if not: abort with message about Docker VMM bug
   - Calculate logical size with `ls -la "$DOCKER_RAW_PATH" | awk '{print $5}'` divided by 1073741824
   - Print INFO line resolving diskSizeMiB discrepancy (settings.json 61035 MiB is stale)

**Output helper functions:**
```bash
PASS=0; FAIL=0
preflight_pass() { echo "[ PASS ] $1"; ((PASS++)); }
preflight_fail() { echo "[ FAIL ] $1"; ((FAIL++)); }
preflight_info() { echo "[ INFO ] $1"; }
preflight_abort() { echo ""; echo "ABORT: $1"; echo "Fix the issue above, then re-run pre-flight."; exit 1; }
```

**Summary block at end:**
- Print blank line
- If FAIL == 0: "All $PASS pre-flight checks passed. Safe to proceed to Phase 2."
- If FAIL > 0: "$FAIL check(s) failed. Fix all failures before proceeding." then `exit 1`

Make executable: `chmod +x preflight.sh`
